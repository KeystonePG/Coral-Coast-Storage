# Coral Coast Self Storage

"Coming soon" style site for a planned indoor + open-air self storage facility near Port Denison, WA. The facility is still in the planning/zoning stage (not built, opening date not confirmed) — this site is a lead-generation page, not a live booking/pricing site.

Content in `lib/content.ts` is sourced from the business plan, cost estimate and competitor analysis prepared by Keystone Property Group (27 August 2026). Pricing shown is explicitly labelled as planning-stage/indicative, not a live rate card.
